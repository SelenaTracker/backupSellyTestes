Termos de Uso

Ao acessar e utilizar o site Selena Gomez Tracker, você concorda com os seguintes termos:

1. Uso Informativo

Este site é uma ferramenta fanmade (feita por fãs) e tem caráter meramente informativo. Os dados de streams são coletados para ajudar na organização de metas da comunidade.

2. Precisão dos Dados

Embora façamos o melhor para manter os números atualizados, os dados podem apresentar pequenas variações em relação aos números oficiais em tempo real do Spotify.

3. Vínculos

Não possuímos qualquer vínculo oficial com a artista Selena Gomez, sua gravadora ou com o Spotify. Este é um projeto independente de fã para fã.
